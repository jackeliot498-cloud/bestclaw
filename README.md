# BestClaw Agent Hub

A Vite + React + Tailwind website for a Claw-class Agent Hub with a modern dark UI and neon accents.

## Sections Included

- Hero
- Featured Agents
- Categories
- Agent Cards grid
- How It Works
- Testimonials
- Pricing
- FAQ
- CTA

## Setup

```bash
npm install
```

## Run Dev Server

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
